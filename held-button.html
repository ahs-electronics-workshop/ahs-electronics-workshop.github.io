Python Moment #4: Two booleans and a held button

The logic behind PWM Challenge 2: one variable remembers whether the button is held, another remembers whether the thing is on, and both have to be true before the level climbs.

There's no button here, so each program reads a list instead. A "down" or "press" is the moment the button goes down, "up" or "release" is the moment it comes back up, and "-" means nothing new happened: the button is still in whatever position it was.
