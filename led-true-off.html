Why does True turn the LED off?

Because True doesn't mean "on". It means put 3.3 volts on the pin. The onboard LED is already connected to 3.3 V on its other side, so when the pin is also at 3.3 V there's no push to make electricity flow through it.

The code you've been writing

# make the red LED something we can control
ledR = digitalio.DigitalInOut(board.LED_RED)
ledR.direction = digitalio.Direction.OUTPUT

ledR.value = True     # red is OFF
ledR.value = False    # red is ON

Backwards? Try it below and watch what True and False do to the voltage.

Think of voltage as water height

Water only flows from high to low. The LED is a little water wheel in the pipe: it only spins when water is moving.

ledR.value = True

Same height on both sides. Nothing flows, so the LED stays dark.

ledR.value = False

High on one side, low on the other. Electricity flows through the LED and it lights up.

Make your code read the right way

Give the two values names that say what they do. Then the rest of your program reads like English.

ON, OFF = False, True    # onboard LED is backwards (active-low)

ledR.value = OFF          # start dark
ledG.value = ON           # green on

Predict the color

The onboard LED has three colors inside it. Turn on more than one and they mix. Decide your answer before you reveal it.

Question 1 
ledR.value = False
ledG.value = True
ledB.value = True

What color is the LED?

Red. Only red is False, so only red is on.
Question 2 
ledR.value = False
ledG.value = False
ledB.value = True

What color is the LED?

Yellow. Red and green are both on, and red + green light mix to yellow.
Question 3 
ledR.value = True
ledG.value = True
ledB.value = True

What color is the LED?

Off. Every pin is at 3.3 V, so nothing flows. This is how most programs start.
